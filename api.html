Static JSON (GitHub Pages)

Every result includes license, licenseUrl, creator, url (source page) and a ready-made attribution line.

  • api/items.json: the full index
  • api/creators.json: creators with asset counts
  • api/meta.json: counts per source and license, build time
  • api/source/{polyhaven|quaternius|kenney|opengameart}.json, api/license/{cc0|cc-by}.json, api/format/{glb|gltf|fbx|obj|blend|png|hdr}.json

Static hosting cannot run queries. Download one of the files above and filter it, or use src/lib.mjs search().

Search endpoint (Docker server)

GET /api/search?q=chair&format=GLB&license=CC0&style=realistic&kind=3d&source=polyhaven&creator=slug&limit=50&offset=0
→ {"total":12,"offset":0,"limit":50,"results":[{"id":"polyhaven:ArmChair_01","title":"Arm Chair 01","creator":"Kirill Sannikov","license":"CC0","licenseUrl":"…","url":"…","attribution":"…",…}]}

Run it with docker compose up. Also available: /api/creators, POST /api/track, /api/stats.

Tracking, and its limits

On GitHub Pages, per-creator views and outbound clicks are stored in your own browser's localStorage. There are no global totals. Setting trackEndpoint in config.json (for example, the Docker server's /api/track) also sends anonymous events there with navigator.sendBeacon.
